## Overview

For e-commerce platforms not directly supported, Fanfare provides a comprehensive REST API for building custom integrations. This enables:

- Product catalog management
- Consumer data synchronization
- Order creation and tracking
- Experience management

## API Capabilities

### Product Management

Create and manage products programmatically. Product variants are the sellable units, so send variant prices as decimal strings:

```bash
# Create a product
POST /products
Content-Type: application/json

{
  "name": "Limited Edition Sneakers",
  "description": "Exclusive release",
  "url": "https://store.example/products/limited-edition-sneakers",
  "variants": [
    {
      "sku": "SNKR-001-9",
      "price": "199.99",
      "inventoryQuantity": 100,
      "inventoryPolicy": "deny",
      "optionValues": [
        { "optionName": "Size", "value": "9" }
      ]
    }
  ]
}
```

### Consumer Sync

Import consumers from your e-commerce platform:

```bash
# Create a consumer
POST /consumers
Content-Type: application/json

{
  "email": "customer@example.com",
  "fullName": "John Doe",
  "phone": "+15551234567"
}
```

### Order Integration

Report completed orders back to Fanfare through the Checkout API or the generated endpoint for your integration path. Keep authoritative money values as decimal strings:

```bash
# Example order completion payload shape
Content-Type: application/json

{
  "consumerId": "con_123",
  "distributionId": "dist_456",
  "externalOrderId": "YOUR-ORDER-123",
  "totalAmount": "199.99",
  "currencyCode": "USD",
  "items": [
    {
      "productId": "prod_123",
      "variantId": "var_456",
      "quantity": 1,
      "unitAmount": "199.99"
    }
  ]
}
```

## Integration Patterns

### Product Sync

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│    Your     │────▶│   Fanfare   │────▶│   Fanfare   │
│   E-comm    │     │    API      │     │   Products  │
└─────────────┘     └─────────────┘     └─────────────┘
```

**Recommended approach:**

1. Export products from your platform
2. Transform to Fanfare format
3. POST to the generated Admin API product endpoint
4. Store the mapping of IDs

### Checkout Flow

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   Fanfare   │────▶│   Checkout  │────▶│    Your     │
│   Winner    │     │   Redirect  │     │  Checkout   │
└─────────────┘     └─────────────┘     └─────────────┘
        │                                       │
        │                                       │
        └───────────────────────────────────────┘
                    Order Callback
```

**Implementation:**

1. Configure checkout URL in experience settings
2. Fanfare redirects winners with consumer/product data
3. Process payment on your platform
4. Callback to Fanfare with order confirmation using decimal-string money fields

## Authentication

API requests require authentication:

```bash
Authorization: Bearer YOUR_API_TOKEN
```

Obtain tokens from **Settings** > **API Keys** in the admin dashboard.

## Rate Limits

| Endpoint  | Rate Limit  |
| --------- | ----------- |
| Products  | 100 req/min |
| Consumers | 100 req/min |
| Orders    | 50 req/min  |

## Best Practices

### Idempotency

Use idempotency keys for create operations:

```bash
X-Idempotency-Key: unique-request-id-123
```

### Error Handling

Handle common error responses:

| Status | Description             |
| ------ | ----------------------- |
| 400    | Invalid request data    |
| 401    | Authentication required |
| 403    | Permission denied       |
| 429    | Rate limit exceeded     |
| 500    | Server error            |

### Pagination

List endpoints support cursor pagination:

```bash
GET /products?cursor=abc123&limit=50
```

## Example Integrations

### Node.js

```typescript
await fetch("https://admin.fanfare.io/api/products", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.FANFARE_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    name: "Product Name",
    url: "https://store.example/products/product-name",
    variants: [
      {
        sku: "SKU-123",
        price: "99.99",
        inventoryQuantity: 25,
        inventoryPolicy: "deny",
      },
    ],
  }),
});
```

### Python

```python
import requests

headers = {
    "Authorization": f"Bearer {api_key}",
    "Content-Type": "application/json"
}

response = requests.post(
    "https://admin.fanfare.io/api/products",
    headers=headers,
    json={
        "name": "Product Name",
        "url": "https://store.example/products/product-name",
        "variants": [{
            "sku": "SKU-123",
            "price": "99.99",
            "inventoryQuantity": 25,
            "inventoryPolicy": "deny"
        }]
    }
)
```
