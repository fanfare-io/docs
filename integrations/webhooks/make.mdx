## Planned Features

### Triggers

Instant triggers from Fanfare:

| Trigger           | Description                |
| ----------------- | -------------------------- |
| Consumer Created  | New consumer registered    |
| Experience Joined | Consumer enters experience |
| Winner Selected   | Draw/auction winner chosen |
| Order Completed   | Order finalized            |

### Actions

Operations in Fanfare:

| Action          | Description                 |
| --------------- | --------------------------- |
| Create Consumer | Add new consumer            |
| Update Consumer | Modify consumer data        |
| Add to Audience | Add to audience list        |
| Get Experience  | Retrieve experience details |

### Searches

Find data in Fanfare:

| Search           | Description              |
| ---------------- | ------------------------ |
| Find Consumer    | Search by email/phone    |
| List Experiences | Get active experiences   |
| Get Distribution | Get distribution details |

## Example Scenarios

### CRM Sync

1. **Trigger**: Consumer Created in Fanfare
2. **Action**: Create Contact in HubSpot
3. **Action**: Add to Mailchimp list

### Multi-step Automation

1. **Trigger**: Winner Selected
2. **Filter**: Check if VIP customer
3. **Action**: Send personalized email
4. **Action**: Create task in Asana
5. **Action**: Log to Google Sheets

## Workaround: HTTP Module

Until the native Make app is available:

1. Use Make's HTTP module
2. Connect to Fanfare API
3. Poll for changes or receive webhooks
