The HubSpot integration will enable you to:

- Sync Fanfare consumers with HubSpot contacts
- Track experience participation as contact properties
- Trigger HubSpot workflows from Fanfare events
- View engagement data in HubSpot timeline

## Planned Features

### Contact Sync

- Create contacts from Fanfare consumers
- Update existing contact properties
- Bidirectional sync support

### Custom Properties

- Experience participation history
- Win/loss status
- Lifetime value from Fanfare

### Workflow Triggers

- Contact enters experience
- Contact wins/loses
- Order completion

### Timeline Events

- Experience participation logged to contact timeline
- Rich event data for sales context

## Alternative: Custom API

Until the HubSpot integration is available, use the [Custom API](/integrations/e-commerce/custom-api) to build a custom sync via HubSpot's API.
