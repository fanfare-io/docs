The Mailchimp integration will enable you to:

- Import Mailchimp audiences as Fanfare audiences
- Sync consumer data bidirectionally
- Trigger email campaigns based on experience events
- Track email engagement in Fanfare

## Planned Features

### Audience Sync

- Import existing Mailchimp audiences
- Export Fanfare consumers to Mailchimp
- Automatic sync on changes

### Campaign Triggers

- Send emails when consumers join experiences
- Notify winners automatically
- Follow-up campaigns for non-winners

### Merge Tags

- Pass Fanfare data to Mailchimp merge tags
- Personalize emails with experience details
- Include checkout links and product info

## Alternative: Klaviyo
