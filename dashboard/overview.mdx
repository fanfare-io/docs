# Dashboard Overview

The Fanfare admin console provides a centralized interface for managing your experiences, audiences, consumers, products, and organization settings. This guide walks you through the main navigation and dashboard features.

## Accessing the Dashboard

After signing in to your Fanfare account, you'll land on the main dashboard at `/app/dashboard`. If you're signing in for the first time, you may be prompted to complete organization setup before accessing the dashboard.

## Navigation Structure

The admin console uses a collapsible sidebar for primary navigation. The sidebar contains the following main sections:

| Section         | Description                                             | Route              |
| --------------- | ------------------------------------------------------- | ------------------ |
| **Home**        | Main dashboard with analytics and experience calendar   | `/app/dashboard`   |
| **Products**    | Product catalog management                              | `/app/products`    |
| **Experiences** | Queue, auction, draw, and appointment management        | `/app/experiences` |
| **Audiences**   | Audience segmentation and membership rules              | `/app/audiences`   |
| **Customers**   | Consumer profiles and activity history                  | `/app/customers`   |
| **Loyalty**     | Loyalty program and tier management                     | `/app/loyalty`     |
| **Locations**   | Physical location management                            | `/app/locations`   |
| **Settings**    | Organization, brand, integrations, and payment settings | `/app/settings`    |

### Sidebar Behavior

The sidebar can be collapsed to show only icons, providing more screen space for content. Click the sidebar trigger button to toggle between expanded and collapsed states.

## Main Dashboard Components

### Analytics Panels

The dashboard provides real-time analytics with two main views:

1. **Channel Attribution View** - Shows traffic sources and conversion funnels
2. **Audience Segmentation View** - Displays metrics broken down by audience segments

### Time Period Selection

Use the time period selector to adjust the analytics date range:

- **24 hours** - Last 24 hours of activity
- **7 days** - Previous 7 days
- **30 days** - Previous 30 days
- **90 days** - Previous 90 days

### Auto-Refresh

The dashboard supports automatic data refresh every 30 seconds. Toggle auto-refresh on or off using the button next to the refresh icon.

### Experiences Calendar

Below the analytics panels, the dashboard displays your experiences in a calendar view. This provides a visual timeline of scheduled, active, and completed experiences.

- **Create Experience** - Launch the experience creation wizard
- **Create Audience** - Define a new audience segment

## Keyboard Shortcuts

The dashboard supports the following keyboard navigation:

| Shortcut | Action                                |
| -------- | ------------------------------------- |
| `Tab`    | Navigate between interactive elements |
| `Enter`  | Activate focused button or link       |
| `Escape` | Close modals or sheets                |
