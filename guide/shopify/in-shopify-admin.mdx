title: Fanfare inside Shopify admin
description: Check attached drops and launch Fanfare workflows directly from Shopify product and order pages.
---

The Fanfare app adds one status block and two shortcuts directly inside Shopify admin so you don't have to hunt for the right screen:

- **Fanfare experiences block (product pages):** Shows which Fanfare experiences include that product.
- **Create Fanfare experience (product actions):** Imports the product and opens experience creation with it pre-attached.
- **Import order into Fanfare (order actions):** Opens the Fanfare import screen prefilled with that order.

The block is read-only and the actions simply launch the relevant workflow inside Fanfare—all drop configuration stays in the Fanfare app. (Opening Fanfare requires an active plan; see [Install and choose a plan](/guide/shopify/install-and-plans). For the customer-facing storefront block, see [Storefront setup](/guide/shopify/storefront-setup).)

## Before you start

- The Fanfare app is installed on your store.
- Your Shopify staff account can view products and orders in Shopify admin.

## See which experiences use a product

Open any product in Shopify admin (**Products** → select a product) to view the **Fanfare experiences** block.

The block reads what Fanfare already holds and never imports or syncs a product on its own.

<Note>
  Any Shopify product you haven't picked for an experience yet displays **No Fanfare experience yet.** with the summary **Not linked**—that's expected. Note that slow responses can also show this empty state temporarily; check [Troubleshooting](#troubleshooting) before creating a duplicate experience.
</Note>

### Collapsed summary

When collapsed, the block summarizes the product's experiences in a single line:

| Summary | What it means |
| --- | --- |
| `Not linked` | No experience includes this product, or it hasn't been imported into Fanfare (also shown while loading or if the request timed out). |
| *Experience name* · Opens *date* | One upcoming experience. |
| *Experience name* · Closes *date* | One currently open experience. |
| *Experience name* · Closed *date* | One closed experience. |
| *Experience name* · Live now | One open experience with no closing time, or an experience with no open/close timestamps yet. |
| *N* experiences · *K* live | Multiple experiences, with *K* marked **Active**. |
| *N* experiences · opens *date* (lowercase, e.g., `opens nov 21`) | Multiple experiences, none open yet; date shows the next one to open. |
| *N* experiences · all closed | Multiple experiences, all closed. |

### Expanded list

Expand the block to see up to five experiences, ordered open first, then upcoming, then closed. Each row shows:

- The experience name and a **Manage →** link straight into Fanfare
- A badge: **Active**, **Upcoming**, or **Closed**
- A UTC date (including the weekday when within two weeks, e.g., `Closes Fri, Nov 22`), or no date for an open experience without a closing time
- The distribution types used (such as Queue or Draw)

If more than five experiences include the product, select **+ N more →** to open the product's full list in Fanfare.

<Info>
  **Badges vs. Fanfare experience statuses:** The block calculates **Active**, **Upcoming**, and **Closed** strictly from opening and closing timestamps (shown in **UTC**, not your store's time zone)—not from Fanfare's full status chips (**Draft**, **Scheduled**, **Live**, **Ended**, **Ended early**; see [Experiences](/concepts/experiences)). Because drafts and deactivated experiences with no opened distributions have no schedule timestamps, they appear as **Active** (or `Live now`) here. Select **Manage →** to check true status in Fanfare.
</Info>

Remember that this block only reflects attached experiences—it doesn't verify checkout protection. See [Check that a drop is protected](/guide/shopify/checkout-protection#check-that-a-drop-is-protected).

## Start an experience from a product page

You can launch experience creation right from a Shopify product page in two ways:

- **From the Fanfare experiences block** (when no experience exists yet): Open the product in Shopify admin and select **Start a Fanfare experience** under **No Fanfare experience yet.**

{/* image: in-shopify-admin-block-empty */}

- **From the product's actions menu** (works whether or not experiences already exist): Open the product, open the actions menu, choose **Create Fanfare experience**, and select **Create in Fanfare** (**Cancel** closes without changes).

{/* image: in-shopify-admin-create-action */}

Either path opens Fanfare's experience builder with the product automatically imported (or refreshed), attached, and pre-named *product title* experience until you rename it. The product stays in **Products** even if you exit without saving the experience. From there, configure your drop as usual—see [Create an experience](/guide/create/experiences).

<Note>
  If your Shopify store connection needs to be renewed, Fanfare shows `"Reconnect Shopify before syncing this product."` instead of the experience builder—reconnect via [Install and choose a plan](/guide/shopify/install-and-plans) and try again. Other product sync errors match those listed under [Products from Shopify](/guide/shopify/products) (displayed full-page instead of as a toast), and deleted products display `"We can't find that page"`.
</Note>

## Import an order from an order page

On any Shopify order page, choose **Import order into Fanfare** from the actions menu to bring in a paid drop order that didn't sync automatically. Selecting **Open import page** opens Fanfare with the order ID prefilled—nothing is imported until you select **Import order** inside Fanfare. See [Orders with Shopify checkout](/guide/shopify/orders) for eligibility rules, steps, and error messages.

## Troubleshooting

<AccordionGroup>
  <Accordion title="The block says it couldn't load Fanfare experiences">
    `"Couldn't load Fanfare experiences for this product."` means Fanfare couldn't retrieve the product's experiences. Reload the product page to try again.
  </Accordion>
  <Accordion title="The block shows no experiences for a product that has them">
    If Fanfare doesn't respond within about 10 seconds, the block falls back silently to **No Fanfare experience yet.** (`Not linked`) without showing an error. Reload the product page before relying on the empty state.
  </Accordion>
  <Accordion title="The block or an action says it needs a product or order context">
    Messages like `"This block needs a Shopify product context."`, `"This action needs a Shopify product context."`, or `"This action needs a Shopify order context."` mean Shopify didn't pass the current product or order to Fanfare. Reload the page from **Products** or **Orders** in Shopify admin.
  </Accordion>
</AccordionGroup>
