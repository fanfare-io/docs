title: Glossary
description: The words the Fanfare admin and this guide use, what each one means, and what developers and the API call it.
---

This page lists the words you meet in the Fanfare admin, in the Fanfare app in Shopify, and in messages from Fanfare. Each row links to the page that explains the term in full. Where developers, the API or the SDK docs use a different word, the API term column gives it; a blank cell means they use the same word. Status values have their own page, [Status reference](/guide/reference/statuses). Settings that lock and actions that cannot be undone are on [Things that cannot be undone](/guide/reference/cannot-be-undone) and [What locks, and when](/concepts/what-locks-when). Numbers such as defaults and limits are on [Limits and defaults](/guide/reference/limits).

## Drops

| Term | Meaning | API term | Explained in |
| --- | --- | --- | --- |
| **Admit rate** | The most customers a queue lets in per minute: it sets the pace, not the total. | | [Queue](/concepts/distributions/queue) |
| **Allocation Percentages** | In a **Mystery Box** sequence, each product's share of the random assignment; this has nothing to do with stock allocation. | allocation weights | [Add and gate sequences](/guide/create/sequences) |
| **Appointment** | A distribution that hands out bookable time slots instead of products, and never takes payment. | | [Appointment](/concepts/distributions/appointment) |
| **Auction** | A distribution where bidding sets the price: **English**, where the highest bid wins, or **Dutch**, where a falling price is bought by whoever accepts it. | | [Auction](/concepts/distributions/auction) |
| **Automatic entry** | Enters customers who reach a queue, draw or timed release without them pressing a button; it is off by default, and does not apply when customers choose their product, when a card hold is placed as they join, or on a timed release whose stock Fanfare counts. | | [Admission and the payment window](/concepts/admission-and-payment) |
| **Bias toward loyal consumers** | Lets loyalty points weight a draw's random order, or the order of a queue's early arrivals; this guide calls it Fanfair loyalty prioritisation. | | [Loyalty and Fanfair](/concepts/loyalty) |
| **Customer Picks** | The product selection where each customer chooses their own product; it is the default. | | [Add and gate sequences](/guide/create/sequences) |
| **Deactivate** | Ends a distribution, sequence or experience straight away and for good; it is not a pause and cannot be undone. | | [Stop a drop](/guide/drop/deactivate) |
| **Delete** | Removes a distribution, sequence or experience from your admin once nothing in it is live, scheduled or still on hold; deactivate anything still live or scheduled first. | | [Stop a drop](/guide/drop/deactivate) |
| Distribution | How a sequence releases its products during a time window: a queue, draw, auction, timed release or appointment. | mechanism (the type) | [Distributions](/concepts/distributions/overview) |
| **Draw** | A distribution that picks winners at random from everyone who enters, so arriving first gives no advantage. | | [Draw](/concepts/distributions/draw) |
| **Draw at** | When a draw's first selection of winners runs; the create wizard and the edit dialogue call it **Draw date**. | | [Draw](/concepts/distributions/draw) |
| Drop | The occasion an experience exists for, not a separate object; the admin uses the word in places such as **By drop** on **Usage**. | | [Experiences](/concepts/experiences) |
| **Ended early** | Shown on a distribution deactivated before its end, and on a sequence or experience that has stopped with such a distribution in it. | | [Experiences](/concepts/experiences) |
| **Experience** | The container for one drop: its products, time zone, design, announcements and one or more sequences. | | [Experiences](/concepts/experiences) |
| **Mystery Box** | The product selection where Fanfare assigns each customer a product at random by weight. | | [Add and gate sequences](/guide/create/sequences) |
| **Opens** and **Closes** | The start and end of a distribution's window; an experience's own **Opens** and **Closes** are worked out from its distributions. | | [Distributions](/concepts/distributions/overview) |
| **Pause queue** | Stops a live queue letting anyone through while customers keep their place; **Resume queue** starts it again. | | [Change things mid-drop](/guide/drop/live-controls) |
| **Priority** | A sequence's place in the order customers are offered sequences, shown as P1, P2 and so on, lowest first, and set by creation order. | | [Sequences and routing](/concepts/sequences) |
| **Queue** | A distribution that lets customers in at a steady rate: early arrivals are shuffled once, then it is first come, first served. | | [Queue](/concepts/distributions/queue) |
| Sequence | A sequence is one way in to an experience, with its own gates, share of the stock, distributions and waitlist. | | [Sequences and routing](/concepts/sequences) |
| **Settles** | When bidding is due to end, unless a late bid extends it (**Settle at** when you add the auction); the auction is settling from then until **Closes**. | | [Auction](/concepts/distributions/auction) |
| Status chip | The label that shows where an experience, sequence, distribution, order or audience stands. | | [Status reference](/guide/reference/statuses) |
| **Timed Release** | A distribution that opens the sale to everyone at a set time, with no line; customers see it headed "Flash Sale". | | [Timed release](/concepts/distributions/timed-release) |
| Waiting room | The 5 minutes before a queue's **Opens**, when customers can join but nobody is let in. | | [Queue](/concepts/distributions/queue) |
| **Waitlist** | Each sequence's list of customers to tell when it opens, not a distribution; it takes sign-ups while nothing in it is live and more is to come or nothing is scheduled. | | [Waitlists](/concepts/waitlists) |
| **Winner count** | How many winners a draw aims for; where every size has a set number of units, it cannot be more than those units. | | [Draw](/concepts/distributions/draw) |

## Admission and payment

| Term | Meaning | API term | Explained in |
| --- | --- | --- | --- |
| Admission | The right to buy one unit for a limited time, given when a customer gets through a distribution; such a customer is admitted. | grant | [Admission and the payment window](/concepts/admission-and-payment) |
| **Admission expiration** | A draw's payment window, set in seconds on the draw. | | [Admission and the payment window](/concepts/admission-and-payment) |
| **Authorization amount** | The one amount held on each customer's card when a queue or draw pre-authorises; every product on offer must cost exactly that. | | [Admission and the payment window](/concepts/admission-and-payment) |
| **Checkout processor** | Your organisation's choice of who takes payment: **Fanfare** for Fanfare checkout, or **External** for your own store's checkout or Shopify checkout. | | [Checkout options](/concepts/checkout-options) |
| **Custom rate** | A Fanfare fee agreed with you in place of your plan's published rates; it stays when you change plan. | | [Payments and fees](/guide/account/payments) |
| **Fanfare fee** | The fee Fanfare takes from each paid order, shown on the order's **Payment** card; a refund does not return it. | | [Payments and fees](/guide/account/payments) |
| **Payment collection** | When a queue or draw takes the money: afterwards (**Pay when admitted**, **Pay after the win**) or as a card hold (**Pre-authorise on joining**, **Pre-authorise on entry**). | | [Admission and the payment window](/concepts/admission-and-payment) |
| Payment window | The time an admitted customer has to pay before they lose the unit; on a draw it is set by **Admission expiration**. | access window | [Admission and the payment window](/concepts/admission-and-payment) |
| Take rate | Fanfare's percentage fee on each paid order, set by your plan or custom rate and by the distribution type; a custom rate can differ by checkout. | | [Plans and what they unlock](/guide/start/plans) |

## Products and stock

| Term | Meaning | API term | Explained in |
| --- | --- | --- | --- |
| **Adjustment**, **Receipt**, **Write-off** | The stock history entries for a count correction, new units arriving, and units lost, damaged or otherwise unsellable. | | [Manage stock](/guide/create/stock) |
| **Allocated** | The units of a size that your experiences hold. | | [Stock](/concepts/stock) |
| **At risk** | Units in live checkouts that **On hand** no longer covers; normally 0. | | [Stock](/concepts/stock) |
| **Available** | **Supply** minus **Allocated**: what can still go into an experience, negative when the size is over-allocated. | | [Stock](/concepts/stock) |
| Counting | Fanfare tracking a sequence's stock live, from about 10 minutes before it opens; from then a size can only go up. | | [Stock](/concepts/stock) |
| **Held: stock** | A sequence that will not start selling because its size's supply fell below what is allocated, until the size fits again. | | [Stock](/concepts/stock) |
| **In checkout** | Units held by customers who have the right to buy while they pay. | | [Stock](/concepts/stock) |
| **Location** | A place where an appointment runs, with an address, a time zone and opening hours that its slots are cut from. | | [Locations and opening hours](/guide/create/locations) |
| **Move units** | Moves units to another sequence of the same experience or back to **Unassigned**; the only way units leave a counting sequence. | | [Change things mid-drop](/guide/drop/live-controls) |
| **On hand** | **Supply** minus **Sold**. | | [Stock](/concepts/stock) |
| **Opens sold out** | Shown on a size that has no units in a sequence; customers cannot buy it until you give it units. | | [Stock](/concepts/stock) |
| **Product** | Anything an experience sells or gives access to, added once and attached to as many experiences as you like. | | [Add products](/guide/create/products) |
| **Released** | A sequence that has finished selling: its unsold units go back to the experience, and its stock can no longer change. | | [Stock](/concepts/stock) |
| **Sold** | Units whose payment was captured; a refund does not reduce it. | | [Stock](/concepts/stock) |
| **Stock management** | Who keeps a product's count, fixed when the product is created: **Fanfare-managed**, **Not managed**, or **Shopify-managed** for Shopify products when you do not use Fanfare checkout. | | [Stock](/concepts/stock) |
| **Supply** | Opening stock plus every receipt, adjustment, write-off and return recorded since. | | [Stock](/concepts/stock) |
| **Unassigned** | Units an experience holds that it has not given to any of its sequences. | | [Stock](/concepts/stock) |
| **Variant** | One size, colour or other option of a product; stock screens call each one a size. | | [Add products](/guide/create/products) |

## Customers and access

| Term | Meaning | API term | Explained in |
| --- | --- | --- | --- |
| **Audience** | A named group of customers that decides who can enter a sequence and who gets its invite: **Dynamic**, **Static List** or **Imported**. | | [Audiences and access codes](/concepts/audiences) |
| Build | Fanfare working out an audience's member list from scratch; while a drop it gates is open, a **Dynamic** audience is **Held**. | | [Audiences and access codes](/concepts/audiences) |
| **Customer** | A person on record in your organisation; the API, the SDK docs and a few admin labels call them a consumer. | consumer | [Customers and identity](/concepts/customers) |
| Guest and signed-in customer | A signed-in customer entered a one-time code; a guest chose "Continue as guest", gets no messages and can return only in the same browser. | | [Customers and identity](/concepts/customers) |
| Invite | The email a sequence sends its audience's members, inviting them to enter. | | [Invites, waitlist and access-code sends](/guide/create/invites-and-waitlist) |
| Loyalty points | Points a signed-in customer earns from purchases and taking part; they cannot be spent, and count through audiences and Fanfair. | | [Loyalty and Fanfair](/concepts/loyalty) |
| **Loyalty tiers** | A group of 2 to 10 rule-based audiences, each covering a range of one customer field such as lifetime points. | | [Loyalty and Fanfair](/concepts/loyalty) |
| **Order limits** | The most one customer can buy, set on a sequence but counted across the whole experience. | purchase limits | [Add and gate sequences](/guide/create/sequences) |
| Organisation admin and member | The two team roles; only an admin can manage payments, billing, the checkout processor, developer settings, the email sender and text messaging, publish pages, or deactivate. | | [Team members](/guide/account/team) |
| **Shared access code** | One code you hand out that customers type to enter a sequence; access codes are not case-sensitive. | | [Sequences and routing](/concepts/sequences) |
| **Wallet pass** | A loyalty pass for Apple Wallet or Google Wallet that shows a customer's points balance. | | [Loyalty and Fanfair](/concepts/loyalty) |

## Orders

| Term | Meaning | API term | Explained in |
| --- | --- | --- | --- |
| **Order** | A customer's purchase, listed under **Orders**; with Fanfare checkout it appears once the customer submits payment, or when a pre-authorised card hold is captured. | | [Orders and refunds](/guide/learn/orders) |
| **Order status** | Where an order stands; the values are on the status reference. | | [Status reference](/guide/reference/statuses) |
| **Payment status** | Where an order's payment stands, shown under the order status when it adds something. | | [Orders and refunds](/guide/learn/orders) |
| **Refund** | Gives a customer money back on an order; it does not return the Fanfare fee or put units back in stock by itself. | | [Orders and refunds](/guide/learn/orders) |
| **Return to stock** and **Keep out of stock** | Your choice, for each refunded item whose stock Fanfare manages, of whether its units go back into **Supply**. | | [Orders and refunds](/guide/learn/orders) |
| Test order | An order placed with a test payment method, marked with a **Test** chip and left out of revenue, purchase limits and customer metrics. | | [Orders and refunds](/guide/learn/orders) |

## Pages, designs and messages

| Term | Meaning | API term | Explained in |
| --- | --- | --- | --- |
| **Announcement** | An email, text or social post you write and schedule for a drop, in the experience's **Marketing Hub**. | | [Announcements](/guide/create/announcements) |
| **Brand** | Your logo, colours and fonts, one set per organisation, shown on every experience; edits reach live pages without publishing. | | [Brand, templates and designs](/concepts/design) |
| **Design Studio** | Where you edit your brand and keep your templates and widget designs. | | [Templates and widget designs](/guide/create/templates) |
| **Email Sender** | The settings for the name, reply address, postal address and sending domains on the email Fanfare sends for you. | | [Sender identity and sending domain](/guide/create/email-sender) |
| **Hosted page** | An optional web page Fanfare serves for one experience, at an address you can share. | | [Build and publish the hosted page](/guide/create/hosted-page) |

| **Widget** | The part of the page where customers join, enter, bid, book or buy, on your own site or inside the hosted page. | | [Brand, templates and designs](/concepts/design) |

## In the Fanfare app in Shopify

The rest of the vocabulary is the same in both apps.

| Term | Meaning | API term | Explained in |
| --- | --- | --- | --- |
| **Checkout protection** | A checkout rule on Shopify that refuses a protected product unless the customer got access through your experience. | | [Checkout protection](/guide/shopify/checkout-protection) |
| **Manage in Shopify** | Shown, disabled, on every plan in the Fanfare admin when Shopify bills your plan: you change the plan in Shopify. | | [Billing and usage](/guide/account/billing) |
| Shopify checkout | Customers pay in Shopify, which holds the order; you refund it in Shopify. | | [Checkout options](/concepts/checkout-options) |
| **Shopify-managed** | Shopify keeps the product's stock count, and only Shopify checkout may sell it. | | [Products from Shopify](/guide/shopify/products) |
| **Source missing** | A product deleted in Shopify; Fanfare keeps it but will not add it to an experience or sequence. | | [Products from Shopify](/guide/shopify/products) |
| **Sync from Shopify** | Brings a product's changes in Shopify into Fanfare straight away. | | [Products from Shopify](/guide/shopify/products) |
