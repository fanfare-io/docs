title: Glossary

Use this glossary to look up terms you'll encounter in the Fanfare admin, the Fanfare app in Shopify, and messages from Fanfare. Each entry links to the guide that explains it in detail. When the API or SDK docs use a different name, it's listed under **API term** (a blank cell means they use the same term).

Looking for specific values or rules? See [Status reference](/guide/reference/statuses), [Limits and defaults](/guide/reference/limits), [What locks, and when](/concepts/what-locks-when), and [Things that cannot be undone](/guide/reference/cannot-be-undone).

## Drops

| Term | Meaning | API term | Explained in |
| --- | --- | --- | --- |
| **Admit rate** | The maximum number of customers a queue lets in per minute. Sets the pace, not the total capacity. | | [Queue](/concepts/distributions/queue) |
| **Allocation Percentages** | In a **Mystery Box** sequence, each product's share of random assignments. Separate from stock allocation. | allocation weights | [Add and gate sequences](/guide/create/sequences) |
| **Appointment** | A distribution for booking time slots instead of buying products. Appointments don't collect payment. | | [Appointment](/concepts/distributions/appointment) |
| **Auction** | A distribution where bidding sets the price—either **English** (highest bid wins) or **Dutch** (a falling price goes to whoever accepts it first). | | [Auction](/concepts/distributions/auction) |
| **Automatic entry** | Enters customers into a queue, draw, or timed release as soon as they arrive, without clicking a button. Off by default, and doesn't apply when customers pick their product, when a card hold is placed on entry, or on a timed release with Fanfare-counted stock. | | [Admission and the payment window](/concepts/admission-and-payment) |
| **Bias toward loyal consumers** | Weights a draw's random selection or a queue's early-arrival order using loyalty points. This guide calls it Fanfair loyalty prioritization. | | [Loyalty and Fanfair](/concepts/loyalty) |
| **Customer Picks** | The default product selection mode, where each customer chooses their own product. | | [Add and gate sequences](/guide/create/sequences) |
| **Deactivate** | Permanently ends a distribution, sequence, or experience right away. It's not a pause and can't be undone. | | [Stop a drop](/guide/drop/deactivate) |
| **Delete** | Permanently removes a distribution, sequence, or experience from your admin once nothing in it is live, scheduled, or still winding down. Deactivate anything live or scheduled first. | | [Stop a drop](/guide/drop/deactivate) |
| Distribution | How a sequence releases products during a time window—a queue, draw, auction, timed release, or appointment. | mechanism (the type) | [Distributions](/concepts/distributions/overview) |
| **Draw** | A distribution that selects winners at random from all entrants, so arriving early gives no advantage. | | [Draw](/concepts/distributions/draw) |
| **Draw at** | When a draw runs its first winner selection. Labeled **Draw date** in the experience wizard and edit dialog. | | [Draw](/concepts/distributions/draw) |
| Drop | The launch event an experience powers—not a separate object. Appears in admin labels like **By drop** on **Usage**. | | [Experiences](/concepts/experiences) |
| **Ended early** | Shown on a distribution deactivated before its scheduled close, and on a sequence or experience that stopped with a deactivated distribution inside it. | | [Experiences](/concepts/experiences) |
| **Experience** | The container for a drop, holding its products, time zone, design, announcements, and one or more sequences. | | [Experiences](/concepts/experiences) |
| **Mystery Box** | The product selection mode where Fanfare assigns each customer a product at random based on your configured weights. | | [Add and gate sequences](/guide/create/sequences) |
| **Opens** and **Closes** | The start and end of a distribution's window. An experience's own **Opens** and **Closes** times are calculated from its distributions. | | [Distributions](/concepts/distributions/overview) |
| **Pause queue** | Temporarily stops a live queue from admitting shoppers while everyone keeps their place. Select **Resume queue** to start admitting again. | | [Change things mid-drop](/guide/drop/live-controls) |
| **Priority** | The order in which Fanfare offers sequences to customers (shown as P1, P2, and so on—lowest number first), set by creation order. | | [Sequences and routing](/concepts/sequences) |
| **Queue** | A distribution that admits customers at a steady pace. Early arrivals are shuffled once at open, then entry is first come, first served. | | [Queue](/concepts/distributions/queue) |
| Sequence | One entry path into an experience, with its own access gates, share of stock, distributions, and waitlist. | | [Sequences and routing](/concepts/sequences) |
| **Settles** | When auction bidding is scheduled to end unless a late bid extends it (labeled **Settle at** when adding an auction). The auction settles from then until **Closes**. | | [Auction](/concepts/distributions/auction) |
| Status chip | The badge showing the current state of an experience, sequence, distribution, order, or audience. | | [Status reference](/guide/reference/statuses) |
| **Timed Release** | A distribution that opens sales to everyone at a set time with no line. Customers see it titled "Flash Sale". | | [Timed release](/concepts/distributions/timed-release) |
| Waiting room | The 5-minute window before a queue's **Opens** time when customers can join, before anyone is admitted. | | [Queue](/concepts/distributions/queue) |
| **Waitlist** | Each sequence's notification list for customers who want to know when it opens (not a distribution). Accepts sign-ups while nothing in the sequence is live and more is coming, or nothing is scheduled yet. | | [Waitlists](/concepts/waitlists) |
| **Winner count** | How many winners a draw targets. When every variant has a fixed unit count, it can't exceed those total units. | | [Draw](/concepts/distributions/draw) |

## Admission and payment

| Term | Meaning | API term | Explained in |
| --- | --- | --- | --- |
| Admission | A time-limited right to buy one unit, granted when a customer gets through a distribution. | grant | [Admission and the payment window](/concepts/admission-and-payment) |
| **Admission expiration** | A draw's payment window, configured in seconds on the draw. | | [Admission and the payment window](/concepts/admission-and-payment) |
| **Authorization amount** | The single amount held on each customer's card when a queue or draw uses pre-authorization. Every product offered must match this exact price. | | [Admission and the payment window](/concepts/admission-and-payment) |
| **Checkout processor** | Your organization's choice of who takes payment: **Fanfare** for Fanfare checkout, or **External** for your own store checkout or Shopify checkout. | | [Checkout options](/concepts/checkout-options) |
| **Custom rate** | A negotiated Fanfare fee that replaces your plan's standard take rates and carries over if you change plans. | | [Payments and fees](/guide/account/payments) |
| **Fanfare fee** | The fee Fanfare deducts from each paid order, shown on the order's **Payment** card. Refunding an order doesn't return this fee. | | [Payments and fees](/guide/account/payments) |
| **Payment collection** | When a queue or draw collects payment—afterward (**Pay when admitted**, **Pay after the win**) or upfront as a card hold (**Pre-authorise on joining**, **Pre-authorise on entry**). | | [Admission and the payment window](/concepts/admission-and-payment) |
| Payment window | How long an admitted customer has to pay before losing their unit. On a draw, this is set by **Admission expiration**. | access window | [Admission and the payment window](/concepts/admission-and-payment) |
| Take rate | Fanfare's percentage fee on each paid order, determined by your plan (or custom rate) and the distribution type. Custom rates can vary by checkout. | | [Plans and what they unlock](/guide/start/plans) |

## Products and stock

| Term | Meaning | API term | Explained in |
| --- | --- | --- | --- |
| **Adjustment**, **Receipt**, **Write-off** | Stock history entries for count corrections, newly received units, and lost, damaged, or unsellable units. | | [Manage stock](/guide/create/stock) |
| **Allocated** | Units of a variant reserved for your experiences. | | [Stock](/concepts/stock) |
| **At risk** | Units in active checkouts that **On hand** inventory no longer covers (normally 0). | | [Stock](/concepts/stock) |
| **Available** | **Supply** minus **Allocated**—units still free to assign to an experience (negative if over-allocated). | | [Stock](/concepts/stock) |
| Counting | Live stock tracking for a sequence, starting about 10 minutes before it opens. Once counting starts, variant allocations can only increase. | | [Stock](/concepts/stock) |
| **Held: stock** | A sequence paused from opening because a variant's supply fell below its allocation. Clears once supply covers the allocation again. | | [Stock](/concepts/stock) |
| **In checkout** | Units temporarily held by admitted customers while they complete payment. | | [Stock](/concepts/stock) |
| **Location** | A physical venue where an appointment runs, with an address, time zone, and opening hours used to generate bookable slots. | | [Locations and opening hours](/guide/create/locations) |
| **Move units** | Moves units to another sequence in the same experience or back to **Unassigned**—the only way to take units out of a counting sequence. | | [Change things mid-drop](/guide/drop/live-controls) |
| **On hand** | **Supply** minus **Sold**. | | [Stock](/concepts/stock) |
| **Opens sold out** | Shown on a variant with no units assigned in a sequence. Customers can't buy it until you allocate units. | | [Stock](/concepts/stock) |
| **Product** | Anything an experience sells or grants access to. Add a product once and attach it to as many experiences as you like. | | [Add products](/guide/create/products) |
| **Released** | A sequence that has finished selling. Its unsold units return to the experience, and its stock can no longer change. | | [Stock](/concepts/stock) |
| **Sold** | Units with captured payments. Refunding an order doesn't reduce this count. | | [Stock](/concepts/stock) |
| **Stock management** | Who tracks a product's count, locked when the product is created: **Fanfare-managed**, **Not managed**, or **Shopify-managed** (for Shopify products when not using Fanfare checkout). | | [Stock](/concepts/stock) |
| **Supply** | Opening stock plus every receipt, adjustment, write-off, and return recorded since. | | [Stock](/concepts/stock) |
| **Unassigned** | Units allocated to an experience that haven't been assigned to any sequence yet. | | [Stock](/concepts/stock) |
| **Variant** | One size, color, or other option of a product. Stock screens refer to each variant as a size. | | [Add products](/guide/create/products) |

## Customers and access

| Term | Meaning | API term | Explained in |
| --- | --- | --- | --- |
| **Audience** | A named customer group that controls who can enter a sequence and who receives its invite: **Dynamic**, **Static List**, or **Imported**. | | [Audiences and access codes](/concepts/audiences) |
| Build | When Fanfare computes an audience's member list from scratch. While a drop it gates is open, a **Dynamic** audience stays **Held**. | | [Audiences and access codes](/concepts/audiences) |
| **Customer** | A person with a profile in your organization. The API, SDK docs, and a few admin labels refer to them as a consumer. | consumer | [Customers and identity](/concepts/customers) |
| Guest and signed-in customer | Signed-in customers verify with a one-time code. Guests choose "Continue as guest", receive no messages, and can only return from the same browser. | | [Customers and identity](/concepts/customers) |
| Invite | The email a sequence sends to its audience members inviting them to enter. | | [Invites, waitlist and access-code sends](/guide/create/invites-and-waitlist) |
| Loyalty points | Points a signed-in customer earns from purchases and drop participation. They can't be redeemed directly, and power loyalty audiences and Fanfair prioritization. | | [Loyalty and Fanfair](/concepts/loyalty) |
| **Loyalty tiers** | A group of 2 to 10 rule-based audiences, each covering a range of one customer field such as lifetime points. | | [Loyalty and Fanfair](/concepts/loyalty) |
| **Order limits** | The maximum quantity one customer can buy—set on a sequence, but counted across the whole experience. | purchase limits | [Add and gate sequences](/guide/create/sequences) |
| Organization admin and member | The two team roles. Only an admin can manage payments, billing, the checkout processor, developer settings, email sender and SMS settings, publish pages, or deactivate drops. | | [Team members](/guide/account/team) |
| **Shared access code** | A single code you distribute that customers type to unlock a sequence. Access codes aren't case-sensitive. | | [Sequences and routing](/concepts/sequences) |
| **Wallet pass** | A loyalty pass for Apple Wallet or Google Wallet showing a customer's points balance. | | [Loyalty and Fanfair](/concepts/loyalty) |

## Orders

| Term | Meaning | API term | Explained in |
| --- | --- | --- | --- |
| **Order** | A customer's purchase, listed under **Orders**. With Fanfare checkout, an order appears once payment is submitted or a pre-authorized card hold is captured. | | [Orders and refunds](/guide/learn/orders) |
| **Order status** | The current state of an order. See [Status reference](/guide/reference/statuses) for every value. | | [Status reference](/guide/reference/statuses) |
| **Payment status** | The state of an order's payment, shown below the order status when it adds detail. | | [Orders and refunds](/guide/learn/orders) |
| **Refund** | Returns money to a customer on a paid order. Refunds don't return the Fanfare fee or automatically return units to stock. | | [Orders and refunds](/guide/learn/orders) |
| **Return to stock** and **Keep out of stock** | Your choice per refunded Fanfare-managed item on whether its units go back into **Supply**. | | [Orders and refunds](/guide/learn/orders) |
| Test order | An order placed with a test payment method—badged **Test** and excluded from revenue, purchase limits, and customer metrics. | | [Orders and refunds](/guide/learn/orders) |

| Term | Meaning | API term | Explained in |

## On Shopify

All other terms work the same in both the standalone Fanfare admin and the Shopify app.

| Term | Meaning | API term | Explained in |
| --- | --- | --- | --- |
| **Checkout protection** | A Shopify checkout rule that blocks checkout for a protected product unless the customer gained access through your experience. | | [Checkout protection](/guide/shopify/checkout-protection) |
| **Manage in Shopify** | Shown disabled on plans in the Fanfare admin when Shopify bills your subscription—change your plan in Shopify instead. | | [Billing and usage](/guide/account/billing) |
| Shopify checkout | Customers pay directly in Shopify, which owns the order and handles refunds. | | [Checkout options](/concepts/checkout-options) |
| **Shopify-managed** | Shopify tracks the product's stock count, and only Shopify checkout can sell it. | | [Products from Shopify](/guide/shopify/products) |
| **Source missing** | Flags a product deleted in Shopify. Fanfare keeps the record, but you can't add it to an experience or sequence. | | [Products from Shopify](/guide/shopify/products) |
| **Sync from Shopify** | Pulls a product's latest changes from Shopify into Fanfare immediately. | | [Products from Shopify](/guide/shopify/products) |
