## Quick Reference

### Package Names

| Package  | npm              | Description                |
| -------- | ---------------- | -------------------------- |
| Core SDK | `@fanfare/sdk`   | Framework-agnostic core    |
| React    | `@fanfare/react` | React hooks and components |
| SolidJS  | `@fanfare/solid` | SolidJS primitives         |

### Key Hooks

```tsx
// Journey management (recommended)
const { status, journey, start } = useExperienceJourney(experienceId);

// Direct distribution access
const { enter, leave, position } = useQueue(queueId);
const { enter, withdraw, isWinner } = useDraw(drawId);
const { placeBid, currentBid, isWinning } = useAuction(auctionId);

// Authentication
const { session, login, logout } = useFanfareAuth();
```

### Common Events

```tsx
// Listen for SDK events
fanfare.on("queue:admitted", (data) => {
  /* ... */
});
fanfare.on("queue:position-changed", (data) => {
  /* ... */
});
fanfare.on("draw:won", (data) => {
  /* ... */
});
fanfare.on("draw:lost", (data) => {
  /* ... */
});
fanfare.on("auction:outbid", (data) => {
  /* ... */
});
fanfare.on("auction:won", (data) => {
  /* ... */
});
```
